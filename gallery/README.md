# 画廊

放摄影作品和生活照的地方。网格用 CSS 多栏瀑布流排版，照片保持原始比例、不裁剪。

## 如何添加一张照片

### 1. 把照片放进 `images/gallery/`

文件名建议用英文短横线，例如 `sydney-kiama.jpg`。支持 `.jpg` / `.jpeg` / `.png` / `.webp`。

### 2. 创建同名的 `.md` 文件，内容就是图注

`images/gallery/sydney-kiama.md`：

```
2026.10.05 Kiama, Sydney
```

文件里的内容会原样作为图注显示，多个换行会被折叠成一行。**没有对应 `.md` 的照片也会显示，只是没有图注**，脚本会打印一条 `⚠` 提示。

### 3. 运行脚本

```bash
python3 gallery/update-gallery.py
```

脚本会生成缩略图、把照片数据写进 `gallery/index.html`，并打印一份清单。

## 说明

- **缩略图自动生成**在 `images/gallery/thumbs/`，长边 700px、质量 82。原图不动，点击缩略图打开的是原图。原图放了几 MB 也没关系，网格只加载缩略图。
- **排序**：默认按图注开头的日期（支持 `2026.10.05` / `2026-10-05` / `2026/10/5`）倒序，新的在前；没有日期的排在最后，按文件名排。想自己定顺序就用下面的 `order.txt`。
- **可重复运行**：照片没变就不会重新生成缩略图；照片删掉后，多余的缩略图会在下次运行时自动清理。
- **缩略图要一起提交**。GitHub Pages 是纯静态的，不会在部署时生成缩略图，所以 `thumbs/` 目录必须进仓库。
- **依赖 Pillow**：`pip install Pillow`。手机照片的旋转信息在 EXIF 里，脚本会先做 `exif_transpose`，所以竖着拍的照片不会躺着显示。

## 手动调整顺序（order.txt）

默认顺序由日期决定，所以日期不同或相同的照片你没法自由对调。要自己控制顺序，就编辑 `images/gallery/order.txt`：

```
# 一行一个文件名，上面的排前面
Yunna-Longkan Wharf2.jpg
Nanjing.jpg

sydney-kiama.jpg
```

- 文件名要写**磁盘上的真实名字**，带空格就照写（`Yunna-Longkan Wharf2.jpg`），不用写成 `%20`。
- **只列一部分也行**：列出来的按列表顺序排在前面，没列出来的自动按日期倒序接在后面。
- 以 `#` 开头的行会被忽略，可以当注释。
- 写错文件名不会报错，但会打印一句 `⚠ order.txt 里的 xxx 没有对应照片，已忽略`，看到就知道拼错了。

改完 `order.txt` 要重新运行 `python3 gallery/update-gallery.py` 才生效。

## 排版与页面

- 布局是 CSS 多栏瀑布流：宽屏 3 栏，窄于 900px 变 2 栏。照片按原始比例排布，不会被裁成正方形，但阅读顺序是**沿每一栏往下**，不是横着从左到右。
- `gallery/index.html` 里的 `galleryPhotos` 数组由脚本生成，**不要手改**，改了下次运行会被覆盖。
- 页面自带 中文 / English 切换，和主页共用 `localStorage` 里的语言设置。
